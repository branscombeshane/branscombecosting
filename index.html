Import previous payrolls

One-off backfill for months from before this app was used — e.g. this tax year's earlier months from an old spreadsheet. Drop a CSV file below, or paste the lines directly into the box — one line per employee per month, 27 comma-separated columns each (see SETUP.md for the exact column order and a worked example). An employee is matched by Employee # only, never by name — if no employee has that number yet, one is created for you to check over on the Roster afterwards. Importing the same employee/month twice overwrites rather than duplicating.
