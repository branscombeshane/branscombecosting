Default waste % for round/turned parts
Cylinder legs and other turned parts are cut from staves and lathed round, which uses up a lot more stock than the finished piece itself — this default applies only to material lines the drawing-reader tags as a round/turned shape, not flat panels.
Drawer runner clearance per side (mm)
Drawer box height deduction (mm)
Drawer runner fitting margin (mm)
Most drawings don't show a drawer box's own size — it's worked out here from the drawer opening instead. Box width = opening width minus the per-side clearance (both sides); box height = opening height minus the height deduction; box depth snaps down to the largest standard Blum 560H runner length (250–600mm) that still fits the available carcass depth once the fitting margin is subtracted, then adds the matching runner pair from the rate card. Applies only to material lines the drawing-reader tags as a drawer box.
Labour minutes per component
Labour minutes per hardware item
Base labour hours per job
The Labour line on every new quote now pre-fills itself (still editable, same as a material line) from: every component counted on the bill of materials × the minutes above, plus every hardware item × its own minutes, plus the fixed base hours for design/setup/admin on every job. A round/turned component counts as 2 components and a drawer box as 4, since lathe work and a 4-panel box both take meaningfully longer to build than one flat panel. These three numbers are starting placeholders, not a researched standard — no two workshops build at the same speed, so check the first several quotes' "Actual hours worked" (entered on a saved quote once it's built) against what was estimated here, and adjust these numbers to match Natalie's shop specifically.
Default carcass species
Default carcass thickness (mm)
Most drawings only show the visible parts (tops, fronts, drawer internals, legs) and never call out the structural case itself — when that happens, a Carcass line is added automatically from the overall dimensions, priced on this species/thickness (must match a rate card name, e.g. "Solid Oak - 25mm" for the 25mm default). It includes the outer box (2 sides, a back, a bottom) plus internal dividers worked out from the drawer/door grid the drawing shows — full-height vertical dividers between columns, and a divider per row boundary in each column — a reasonable but approximate stand-in for Natalie's actual construction, flagged on the quote so it's never a silent guess. If the drawing DOES call out its own carcass material, this is skipped entirely.
